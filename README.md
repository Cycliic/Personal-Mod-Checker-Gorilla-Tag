**A custom Gorilla Tag VR utility focused on player information, in-game customization, and immersive interface design.**

Personal Mod Checker is a personal Gorilla Tag modification built to bring an extensive collection of player information tools, configuration options, and room utilities directly into the VR environment. Featuring a fully interactive, hand-mounted interface, the mod is designed around accessibility, responsiveness, and a distinctive visual identity. Every system is built to operate within the VR experience, combining smooth animations, interactive panels, custom audio feedback, and controller-based navigation into a cohesive utility.

The project introduces a range of features designed to provide a more detailed and customizable Gorilla Tag experience, from player inspection and platform identification to configurable visual settings and room management.

## Features

### 🎮 Player Information
- Interactive player leaderboard displaying everyone currently present in the room
- Platform identification for SteamVR, Meta, and Pico
- Player FPS and ping information
- SteamVR world scale display
- Green modification counter showing the number of detected mods
- Conditional mod inspection button
- Dedicated panel displaying available information about detected modifications

### 🔍 Player Inspection
- Finger-mounted laser for selecting players
- Real-time player character preview
- Player username and color information
- Hexadecimal color code display with a corresponding color preview
- Available player modification information
- Integrated reporting options for Toxicity, Cheating, and Hate Speech
- Press X to deselect the current player and return to the selection interface
- VR finger-based scrolling for navigating information panels

### ⚙️ Configuration
- Player hitbox configuration
- Customizable player nametags
- Nametags displaying player name, FPS, ping, and platform
- Dynamic time-of-day controls
- Day, Night, Morning, and Evening settings
- Expandable configuration menus
- Interactive scrolling and controller-based navigation

### 🌐 Room Management
- Disconnect from the current room
- Join a random room
- Room information panel
- Room code display
- Current player count
- Gamemode information
- Queue information
- Expandable and collapsible room information interface

### 🖥️ VR Interface
- Y-button activation using the right controller
- Compact interface attached to the left hand
- Vertical positioning above the left thumb
- Smooth opening and closing animations
- Custom interface click sounds
- Interactive expandable panels
- Responsive controller-based scrolling
- Dedicated Information and Configuration tabs
- Bottom navigation panel
- VR-oriented interface layout designed to minimize visual obstruction

### 🔊 Audio & Interaction
- Custom button click sounds
- Smooth menu transitions
- Interactive selection feedback
- Audio feedback when selecting players
- Responsive button interactions
- Consistent interface behavior across expandable menus

## Project Goals

Personal Mod Checker is designed to bring together player information, customization, and room utilities through an interface specifically created for Gorilla Tag VR. The goal is to create a compact, immersive, and responsive experience that prioritizes usability while maintaining its own distinctive visual identity.

The project focuses on:

- Creating an intuitive VR-native interface
- Providing detailed player information where available
- Organizing multiple utilities into a cohesive system
- Implementing smooth animations and responsive interactions
- Maintaining a clean and structured interface
- Expanding the functionality of a personal Gorilla Tag utility

---

## Development

Personal Mod Checker is a personal project currently focused on developing and refining its interface, functionality, and VR interaction systems.

The project is built around C#, Unity, and the Gorilla Tag modding environment.

**This project is intended for personal use and experimentation within Gorilla Tag.**
